**[ghost-variable](https://github.com/priyanshijoshiii/ghost-variable)** auditing the compas recidivism dataset for racial bias, logistic regression built from scratch in numpy, no sklearn quietly doing the thinking for me. so far the false positive rate comes out to 33% for black defendants against 17% for white defendants, the same gap propublica found in 2016. now working on a second regression to see if race still predicts risk score once priors, age, and sex are controlled for.

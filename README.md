## currently working on

**machine learning:** learning it properly first, working through the deeplearning.ai curriculum start to finish, no jumping ahead to the parts that feel more exciting. i don't just watch and nod along, i build something alongside every concept, a notebook, a small script, whatever makes it real, so i actually know i understood it and i'm not just recognizing the shape of it.

**[ghost-variable](https://github.com/priyanshijoshiii/ghost-variable):** auditing the compas recidivism dataset for racial bias, logistic regression built from scratch in numpy, no sklearn quietly doing the thinking for me. so far the false positive rate comes out to 33% for black defendants against 17% for white defendants, the same gap propublica found in 2016. now working on a second regression to see if race still predicts risk score once priors, age, and sex are controlled for.

## some things i've built

**[articulate](https://articulat-xi.vercel.app):** impromptu speaking trainer, built for myself and anyone else who freezes up when asked to speak without notice. next.js, groq whisper, qwen, llama, mongodb, deployed on vercel. i pick it back up and improve it whenever i get the chance.

**[molgen](https://github.com/priyanshijoshiii/MolGen):** an ai that turns a plain english drug description into 50 candidate molecules, scores them with a graph neural network, and returns the top 5 with pharmaceutical property scores. won electrothon 8.0 as an all-girls team.

**[smart-lead-importer](https://github.com/priyanshijoshiii/smart-lead-importer):** a csv importer that takes leads from any layout, facebook exports, google ads exports, messy manual spreadsheets, whatever, and maps them into a standard crm format using an llm. business rules like duplicate contacts and missing email/phone are enforced in code, not left to the model to decide.

**[studylog](https://github.com/priyanshijoshiii/studyLog):** built to actually understand how convex works. a minimal study timer, start a session, add timestamped notes as you go, take breaks, see your history after.
